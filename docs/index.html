測試沒走到的路，它會走完。

先把程式畫成一張小地圖，讓電腦把每一種先後順序都走一遍，找到會壞的那條路，再把它鎖起來不讓它再壞。

    程式改了，檢查會自己喊

    守門檢查記得它看過的每一段程式。有人改了那一段，它先喊，再請人跑維護。

    什麼時候叫它

    兩個人同時做一件事搶座位、同時付款、同時改同一筆資料、斷線重連掃雷
    金額、帳號、權限總數要對、刪帳號不能留後門、撤銷不能誤殺掃雷
    有地圖的區域又改了程式合併、重構、別人沒跑檢查就改了維護
    要給設計師或老闆看一張圖，用他們的話標每一格畫給人看
    一般的 bug先重現、修、加一個會抓到它的測試就好不用

    報告裡會出現的字

    字意思
    CONFIRMED在真的程式上重現了，而且主 session 自己再跑過一次。
    PLAUSIBLE地圖上壞了，真程式還沒重現。先當線索，不當 bug。
    INCONCLUSIVE跑到一半被時間砍掉。不是通過。
    mutation 表故意拆掉一個防護，檢查有沒有喊。沒喊過的檢查不算數。
    sync commit地圖最後一次確認和程式一樣的那個版本。
    drift guard程式改了、地圖沒改時會喊的那個小測試。
